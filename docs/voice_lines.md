# スコア画面の声：台本

`public/audio/voice/` に `voice01.mp3` から順に置くと、スコア画面で 1 本が無作為に鳴ります。
置いた分だけ候補になるので、増やすときにコードは触りません。連続で同じものは鳴りません。

## 使える音声

配布する場所が公開サイトなので、**権利の切れていない市販作品の音声は置けません**。次のどれかで用意してください。

- **VOICEVOX**（無料の音声合成）。クレジット表記だけで公開物に使えます。いちばん手軽です
- **自分か友人の声を録音**する。いちばん自由です
- 効果音素材サイトの、商用利用可・再配布可のもの

## 作り方（VOICEVOX の場合）

1. https://voicevox.hiroshiba.jp/ から入れる（Windows 版あり）
2. 話者を 2 人決める。まひろ側は落ち着いた声、ちさと側は軽い声だと掛け合いになります
3. 上の表のセリフを打ち込んで、1 行ずつ書き出す
4. wav で出るので mp3 に変換する（1 本 20〜60KB ほど）

   ```bash
   ffmpeg -i voice01.wav -b:a 96k public/audio/voice/voice01.mp3
   ```

5. `public/audio/voice/` に置いて push する
6. クレジットを README に足す（VOICEVOX の規約で必要）

## 調整するところ

- 音量は `Audio.ts` の `playVoice()` の `gain`（今は 0.9）
- 鳴らすまでの間は `Game.ts` の `playVoice(0.9)` の数字（秒）。勝利の音と重ならないようにしてあります
- 上限は `VOICE_MAX`（今は 24 本）
- 置かれているか確かめるには `?voicetest`
