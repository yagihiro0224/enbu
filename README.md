# 炎舞 -ENBU-

スマホのブラウザで遊べる、アニメ調の 3D ボス戦アクション。
妖魔の少女・紫苑が放つ立体弾幕を、回避と受け流し（パリィ）でさばきながらコンボを叩き込む。

Steam の『炎姫』（Crimson Dusk）のコンセプトを参考に、個人の趣味で作ったオマージュ作品です。

## 遊び方

- **キャラ選択**: 開始時に「深川まひろ」「杉本ちさと」から選ぶ。ゲーム中は左上の「交代」（PC は Q）でいつでも入れ替え
- **移動**: 画面左半分をドラッグ（仮想スティック）
- **打**: 連打で 5 段コンボ。素手の格闘で、まひろは重い型（ジャブ → 右フック → アッパー → ハイキック → ジャンプ回し蹴り、赤の効果）、ちさとは鋭い型（刺突 → 手刀の振り下ろし → 掌底の切り上げ → 前蹴り → 回転裏拳、紫の効果）。打撃は弾も消せる。5 段目は衝撃波を飛ばす
- **避**: 無敵つきダッシュ。弾幕を突っ切れる
- **受**: 弾に触れる直前に押すと弾き返して反撃。ボスの突進もパリィできる
- **射**: 遠距離の火弾。削り用
- **回復アイテム**: ステージに 3 個。触れると体力が 30 回復する。1 戦闘につき 1 個 1 回
- **体力はキャラごと**。控えているキャラは少しずつ回復するので、傷んだら交代して休ませる。ただしどちらかが倒れたら負け
- ボスの「体勢」を削り切ると崩し状態になり、大ダメージが入る
- PC では WASD 移動、J 打、K/Space 避、L 受、I 射、Q 交代

## スコアと称号

クリアすると合計スコアと称号が出る。

| ボーナス | 配点 |
|---|---|
| 打撃ヒット | 30万 × 回数 |
| 敵の打撃をパリィ | 50万 × 回数 |
| 敵の弾をパリィ | 10万 × 回数 |
| ノーダメージ | 1000万 |
| クリアタイム | 1分以内 100万 ／ 2分以内 50万 ／ 3分以内 20万 |

上の合計に**コンボ倍率**（1.0〜4.0、最大コンボ 60 で 4 倍）を掛けたものが最終スコア。

称号は 神人間（1億以上）、鬼人間（5000万以上）、上級者人間（1000万以上）、一般人人間（500万以上）、下手人間（それ未満）。
神人間はノーダメージ・短時間・長いコンボを揃えないと出ない。

## 技術

- Three.js + TypeScript + Vite
- 物理エンジンなし。円・カプセル判定を自前実装
- 弾幕は `InstancedMesh` で数百発を一括描画
- キャラクターはプリミティブとろくろ形状で組んだ 7 頭身のアニメ調フィギュア。目はキャンバス描画のテクスチャ、輪郭線は裏面押し出し
- 演出は刀の軌跡、斬撃の三日月、衝撃波、閃光、魔法陣、光の柱に加え、UnrealBloom による発光（低フレームレート時は自動オフ、`?nobloom` で手動オフ）
- 効果音と BGM は WebAudio の合成音（音声ファイルなし）。BGM は場面で厚みが変わり、右上の ♪ で切り替えられる
- PWA 対応（ホーム画面に追加するとフルスクリーンで遊べる）

## VRoid で作ったキャラに差し替える

`public/models/player.vrm` に VRM ファイルを置くだけで、主人公が差し替わります（[@pixiv/three-vrm](https://github.com/pixiv/three-vrm) を使用）。
VRoid Studio の書き出し時に「ポリゴン削減」「テクスチャ統合」を有効にすると、スマホでも軽く動きます。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173  （--host で LAN 内のスマホから確認可）
npm run build    # dist/ に出力
```

動作確認用のクエリ:

- `?autostart` タイトルを飛ばして即開始
- `?t=30` 開始から 30 秒ぶん早送りした状態にする
- `?bot` プレイヤーを自動操作する

## デプロイ

`main` に push すると GitHub Actions が GitHub Pages に自動デプロイします。

## ランキング

タイトルで名前を入れてから遊ぶと、クリア時の点数がランキングに残ります。
名前はこの端末に覚えるので、次からは入れ直さなくて済みます。

記録の置き場所は 2 通りです。

- **何も設定しない場合**: その端末の中だけに残ります。自分の記録を伸ばして遊ぶ形
- **サーバーを用意した場合**: 遊んだ人みんなの記録が 1 つの表に並びます。
  無料枠で動く小さな API を `server/` に置いてあります。手順は `server/README.md`

リザルトの「結果を共有」を押すと、点数と称号を添えてリンクを共有できます。
